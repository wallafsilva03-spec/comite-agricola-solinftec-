Painel Comparativo de Eficiência Operacional — Linha do Tempo

Os dados vêm direto do banco no Supabase, tabela linha_do_tempo (uma linha por evento, com Hora Inicial/Hora Final). Insira/edite linhas pelo Table Editor do Supabase e o painel atualiza automaticamente. Configure filtros gerais e compare 4 períodos. O 2º período é a referência para definir os ofensores. Somente eventos classificados como Improdutivo entram no ranking de ofensores. A opção avançada transforma deslocamentos não produtivos em produtiva quando ativada.

Regras: a duração de cada linha é calculada por Hora Final − Hora Inicial. Horas disponíveis = horas totais − Manutenção. Eficiência operacional = horas produtivas / horas disponíveis. Parado = horas totais − horas produtivas. O ranking de ofensores considera apenas eventos classificados como Improdutivo, e o percentual é calculado sobre o Parado de cada período.
